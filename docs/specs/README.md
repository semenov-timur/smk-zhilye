# Текущие спецификации

Здесь описано, **как система работает сейчас** — по областям
(например, `leads.md`, `content-model.md`, `pages.md`).

Файлы не пишутся вручную заранее: они создаются и обновляются при архивации
выполненных изменений (`docs/changes/`). Если код и спецификация расходятся —
это баг, исправляем код или осознанно меняем спецификацию через новое изменение.
