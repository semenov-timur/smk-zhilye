# Изменения

Каждая задача — отдельная папка `NNN-slug/`:

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `change.md` | вы (агент помогает) | зачем, требования, критерии приёмки, что не входит |
| `tasks.md` | агент, вы утверждаете | план: шаги, файлы, какие тесты закрывают какие критерии |
| `verify.md` | агент | отчёт: каждый критерий — чем подтверждён, статус |

Готовые изменения переносятся в `archive/ГГГГ-ММ-ДД-NNN-slug/`.

Процесс описан в скилле `.claude/skills/spec/SKILL.md`.
Быстрые мелкие правки (текст кнопки, опечатка) делаются без изменения.
