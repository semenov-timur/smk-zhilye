# Дизайн-система

> Заполняется после того, как заказчик согласует макеты ключевых страниц.
> До этого агент не придумывает цвета, шрифты и стиль самостоятельно.

## Исходные данные

- Логотип: _ждём вектор от заказчика_
- Фирменные цвета: _ждём коды_
- Шрифты: _ждём брендбук или выбираем при разработке макетов_
- Референсы, которые нравятся заказчику: _ждём 2–3 ссылки_

## Токены (заполнить)

| Токен | Значение | Где используется |
|---|---|---|
| color-primary | | Кнопки, акценты |
| color-text | | Основной текст |
| font-heading | | Заголовки |
| font-body | | Текст |
| radius | | Скругления карточек и кнопок |
| container | | Максимальная ширина контента |

## Компоненты (заполнить)

Кнопка, карточка услуги, карточка объекта, форма заявки, шапка, подвал,
блок «цифры о компании», блок отзыва.

## Правила

- Mobile first: всё проверяется на ширине 360 px.
- Только реальные фото объектов, без стоков.
- Контраст текста — не ниже WCAG AA.
