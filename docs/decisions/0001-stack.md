# 0001. Стек: Astro + Payload + PostgreSQL, TypeScript

Дата: 2026-11-15 · Статус: принято

## Контекст
Нужен быстрый контентный сайт с админкой для менеджера и приёмом заявок.
Разработчик знает Java и Go, во фронтенде начинающий. Работа ведётся с ИИ-агентом.

## Решение
Сайт — Astro, админка и бэкенд — Payload 3, база — PostgreSQL, всё на TypeScript.

## Почему
- Astro ближе всего к «HTML + шаблоны», даёт лучшую скорость и SEO для контентного сайта.
- Payload даёт модели данных, админку, API, права и хуки без написания бэкенда с нуля.
- Один язык на весь проект; стек хорошо знаком ИИ-агентам.

## Альтернативы
- Next.js + Payload в одном приложении — выше порог входа (React, серверные компоненты).
- Django + Wagtail, Laravel + Filament — другой язык, не даёт преимуществ разработчику.
- Свой бэкенд на Go/Java — пришлось бы писать админку с нуля.
- Directus — лицензия может потребовать оплаты при выручке заказчика выше порога.
- WordPress, 1С-Битрикс, Tilda — слабый контроль, плагины или платная лицензия.
