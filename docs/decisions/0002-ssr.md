# 0002. Сайт рендерится на сервере (SSR)

Дата: 2026-11-15 · Статус: принято

## Решение
Astro работает в режиме SSR с Node-адаптером: страницы собираются при запросе
из актуальных данных Payload.

## Почему
Изменения в админке видны на сайте сразу, без пересборки. При ожидаемой
посещаемости разница в скорости со статической генерацией незаметна.

## Когда пересмотреть
Если нагрузка вырастет или понадобится раздавать сайт через CDN — перейти на
статическую генерацию с пересборкой по хуку из Payload или добавить кэширование.
